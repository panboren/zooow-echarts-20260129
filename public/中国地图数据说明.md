# 中国地图数据文件说明

## 📍 文件信息

- **文件名**: `china-map-full.json`
- **存储位置**: `public/china-map-full.json`
- **数据格式**: GeoJSON
- **数据来源**: 阿里云 DataV

## 📥 获取方式

### 方法一: 直接下载

1. 访问以下 URL 下载中国地图数据:
   ```
   https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json
   ```

2. 将下载的文件重命名为 `china-map-full.json`

3. 将文件放置到项目的 `public` 目录下:
   ```
   zooow-echarts-20260201/
   └── public/
       └── china-map-full.json
   ```

### 方法二: 使用命令行

**Windows (PowerShell)**:
```powershell
Invoke-WebRequest -Uri "https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json" -OutFile "public/china-map-full.json"
```

**Windows (curl)**:
```cmd
curl -o public/china-map-full.json https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json
```

**Linux/Mac**:
```bash
wget -O public/china-map-full.json https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json
# 或
curl -o public/china-map-full.json https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json
```

## 📊 数据内容

该文件包含:
- 中国所有省、自治区、直辖市、特别行政区的边界数据
- 完整的 GeoJSON 格式地理信息
- 适配 ECharts 地图组件使用

## ✅ 验证方法

下载完成后,可以通过以下方式验证:

1. **检查文件大小**: 约 1-2 MB
2. **检查文件格式**: JSON 格式,包含 `type: "FeatureCollection"`
3. **测试组件**: 刷新页面,查看是否显示完整中国地图

## 🔧 使用说明

1. 将文件放置到正确位置后,刷新浏览器
2. 组件会自动加载本地地图数据
3. 如果加载失败,会自动降级到散点图模式
4. 无需修改任何代码

## ❓ 常见问题

### Q: 为什么需要下载这个文件?
A: 组件需要 GeoJSON 格式的地图数据来渲染中国地图轮廓。

### Q: 文件损坏了怎么办?
A: 重新从阿里云 DataV 下载即可。

### Q: 可以使用其他地图数据吗?
A: 可以,但需要确保是 GeoJSON 格式并正确注册到 ECharts。

### Q: 下载失败怎么办?
A: 组件会自动使用散点图模式,不影响基本功能。
